One Dataset, Four Views

Project 2: The same data, shown four different ways. Each view emphasises different parts of the information and serves a different user goal.

Your Project:

  1. Read the data: open data.json and look at a few inspections before you write any code
  2. Decide who each view is for: a diner, a health inspector, a reporter…
  3. Write three views: Table, Category, and Charts. Card View is done for you as an example.
  4. Make each view useful: what does each one emphasise, and what does it leave out?
  5. Write a reflection: how does presentation change what your data seems to say?

Why Four Views?

  • Card View: best for browsing and comparing individual items
  • Table View: best for scanning specific values and sorting
  • Category View: shows groups and how they compare
  • Charts View: shows patterns at a glance, with a text alternative for every chart
