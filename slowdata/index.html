      TODO 3: The same load with async/await

      Still a promise underneath. Why write it this way?

      • It reads top to bottom. Each await waits for one step, so the code reads in the order it happens.
      • Errors go in one place. A try/catch catches a failure at any step.
      • No callbacks inside callbacks. Each step's result is a normal variable you can use on the next line.
